# LICENSES — Third-Party Code and Data

## Policy

1. **No proprietary code** copied from Hevy, Strong, Jefit, Boostcamp, or any commercial app
2. **No Dribbble shot reproduction** — study layout and motion patterns only
3. **AGPL-3.0 repos** (wger) — reference only, no code merged
4. **GPL-3.0 repos** (OpenNutriTracker) — reference only, no code merged
